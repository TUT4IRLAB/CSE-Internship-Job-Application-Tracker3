# 3–5 Minute Demonstration Script
0:00–0:40 — Introduce CareerTrack, a student internship and job application tracker. Explain the problem of losing track of applications.
0:40–1:30 — Open the dashboard and show totals for applied, interview, offer and rejected.
1:30–2:30 — Add an application, demonstrate saving to the Neon database, change its status, filter records and delete a sample.
2:30–3:30 — Open Find Jobs, search for a keyword, visit the original job posting and click Track application to prefill the tracker.
3:30–4:30 — Explain Next.js frontend, Express API, Neon PostgreSQL, GitHub and Vercel/Render deployment. Mention provider limitations and single-user MVP security.
4:30–5:00 — Recap outcomes and future improvements (authentication, local jobs feeds, interview reminders).
